# Bomb_7th

Interactive 7th-grade Computer Literacy circuit/wiring lesson app for Ms. CJ.

## Modes
- Lesson Mode: circuit concepts, troubleshooting, and defusal logic
- Countdown Console: 30/45/60/90 second timers
- Chaos Soundboard: teacher-triggered effects
- Quick Challenge: whole-class response checks

## Teacher keyboard shortcuts
- A = Arm
- P = Pause
- R = Reset
- D = Defused
- W = Wrong wire / -5 seconds
- X = Detonate
- 1 = Bomb-strapped clip
- 2 = Bomb-factory clip

## Audio
Create a `sounds` folder and add:
- `bomb_strapped.mp3`
- `bomb_factory.mp3`

The app will run without audio, but those buttons will be silent until the files are present.

## GitHub Pages
